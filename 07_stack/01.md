# 01.asm

Initial state = Before push, `RSP=0x7fffffffdbb0`

`push rax`: - `RSP` decreases by 8 to `0x7fffffffdba8` - The value `100` is written to `[0x7fffffffdba8]`

`push rbx`: - `RSP` decreases by 8 again. `0x7fffffffdba8` to `0x7fffffffdba0` - The value `200` is written to `[0x7fffffffdba0]` - At the `nop` the stack holds: - Top of the stack RSP and next item below is RSP + 8;

`pop rcx`: - CPU reads the valye sitting at the top of the stack ( 200 ) into `RCX` - `RSP` increases by 8.

`pop rdx`: - CPU reads the next value ( 100 ) into `rdx` - `RSP` increases by 8 back to the original value.

Because of LIFO, `RCX` ends up with 200 from RBX and RDX ends up with 100 from RAX. The stack reversed the order of the two values.

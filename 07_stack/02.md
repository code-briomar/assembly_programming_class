# 02.asm

`call work`: - `call` automatically pushes the returning address ( the instruction after call ) onto the stack. - `RSP` drops by 8.

`push rbp` and `mov rbp, rsp`: - Saves the callers old pointer. `RSP` drops by 8. - `RBP` is set to the new value of `RBP` ( 0x7fffffffdba0 )

`sub rsp, 16`: - Decreases RSP by 16 bytes. - This reserves 16 bytes of space on the stack for local variables without using push.

`mov [rbp - 8], 100`: stores 100 at 0x7fffffffdba0 - 8 = 0x7fffffffdba8.

`mov [rbp - 16], 200`: stores 200 at 0x7fffffffdba0 - 16 = 0x7fffffffdb90.
Reads them back into RAX and RBX.

`mov rsp, rbp:` Gets rid of the 16 bytes of local variables instantly by moving RSP back to 0x7fffffffdba0.

`pop rbp`: Restores the old RBP and moves RSP up to 0x7fffffffdba8.

`ret`: Pops the return address (0x401005) off the stack into the instruction pointer (RIP). RSP moves up to 0x7fffffffdbb0. Back in \_start with a clean stack.

The stack is used as both a memory for local variables and to remember where to return.

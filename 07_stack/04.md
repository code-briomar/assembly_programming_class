# 04.md

`call work`: Pushes the return address (0x08049005)

`push ebp & mov ebp, esp`: Pushes old EBP. ESP drops by 4.EBP is 0xffffcdc8.

`sub esp, 8`: Allocates 8 bytes (space for two 4-byte integers).ESP becomes 0xffffcdc0.

[ebp - 4] is address 0xffffcdc4, gets 100 (0x64)

[ebp - 8] is address 0xffffcdc0, gets 200 (0xc8).

`mov esp, ebp`: resets ESP to 0xffffcdc8.

`pop ebp`: ESP becomes 0xffffcdcc. Resets EBP.

`ret`: pops return address, ESP returns to 0xffffcdd0.
